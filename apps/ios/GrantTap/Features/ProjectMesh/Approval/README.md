# Project approval

`AppModelProjectApproval.swift` persists one desired Project level and offers the
same versioned operation to every authenticated computer participating in that
Project. `ProjectApprovalSection.swift` shows desired state beside each
computer's independently reported actual state. A Mesh execution with no
Project level falls back to ASK and never inherits a machine default.

See the [engineering index](../../../../../../AGENTS.md) and [Project Mesh](../README.md).
