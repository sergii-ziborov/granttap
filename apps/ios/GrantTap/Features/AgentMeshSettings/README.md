# Agents & Mesh

This module owns the user-selected runtime gates for Claude Code, Codex,
Cursor, Grok Build, and Project Mesh. Disabling an integration stops new
GrantTap monitoring without uninstalling the provider or deleting local task,
history, and usage records.

Grok Bot endpoint trust, actors, one-time invites, and revocation are separate
from coding-provider identity and live beside the Project Mesh transport.
