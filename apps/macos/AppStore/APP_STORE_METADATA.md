## English (U.S.)

### Subtitle

`Your coding agents, in view`

### Promotional text

See local agent work, review changes, answer questions and manage Project Mesh from Mac. Optional Personal service connects your devices with encrypted delivery.

### Description

GrantTap is a personal control center for coding agents running on your Mac.
Install the separate GrantTap MCP, then see live tasks, inspect conversations,
review recorded file changes, approve actions and send messages or queue them
for later. Local access is authorized on this Mac; GrantTap does not provide
an AI model or proxy model traffic.

Project Mesh keeps a Task stable across provider sessions and computers.
Inspect confirmed usage, tools, skills and repository evidence where reported.
Unavailable measurements stay unavailable. Hidden reasoning is not forwarded.
Claude Code and Codex are primary integrations; Cursor is Beta. Other providers
work only where their supported controls are available.

Connect iPhone or iPad from Settings with a one-time QR, or add a computer by
link. Apple Watch receives state through its paired iPhone. GrantTap payloads
are end-to-end encrypted. Built-in Help, Terms, Privacy and licenses are
available from Settings and the Mac menus, including offline.

Two ways to use GrantTap on Mac

Active Personal includes this Mac as a managed client, with no additional Mac
Local purchase. A controller-only Mac uses no publishing-computer seat. Install
MCP on every computer that runs agents; a controller-only Mac needs no local MCP.

Mac Local: a separate $39.99 US one-time non-consumable for local Mac control
and personal/internal own-relay setup. No Personal subscription is needed for
that mode. Managed hosting is not included. Direct mode uses encrypted endpoint
discovery; own-relay mode uses your endpoint. Supply reachable TLS or a VPN and
maintain your infrastructure. APNs credentials and guaranteed background delivery
are not included. Restore with the purchasing Apple Account.

Planned US monthly managed plans: Personal $3.99 for up to 2 computers,
Personal Plus $6.99 for 5, Fleet $11.99 for 15. Core features are shared;
only the managed publishing-computer allowance differs. Agents and Tasks are
not billed separately. Models and tokens are separate. Local pricing and any
eligible seven-day trial appear in Apple's purchase sheet. Subscriptions renew
automatically until cancelled in Apple settings. Apple shows plan-change dates.
Cancelling Personal does not delete downloaded local data or revoke purchased
Mac Local. Fleet is a personal computer allowance, not an enterprise SLA.

## Russian

### Subtitle

`Агенты под контролем`

Работа локальных агентов, изменения файлов, вопросы и Project Mesh на Mac. Необязательная Personal соединяет устройства зашифрованной доставкой.

### Description

GrantTap — личный центр управления coding-агентами на вашем Mac. Установите
отдельный GrantTap MCP, наблюдайте задачи, читайте чаты, проверяйте записанные
изменения файлов, подтверждайте действия и отправляйте сообщения сразу или в
очередь. Локальный доступ подтверждается на этом Mac. GrantTap не предоставляет
модель ИИ и не проксирует трафик модели.

Project Mesh сохраняет Task при смене сессии, провайдера и компьютера. Смотрите
подтверждённую статистику, инструменты, skills и данные репозитория. Если замер
недоступен, приложение не придумывает цифру. Скрытые рассуждения не передаются.
Основные интеграции — Claude Code и Codex; Cursor — Beta. Другие провайдеры
поддерживаются только в пределах доступных реализованных действий.

Подключайте iPhone или iPad из Settings одноразовым QR, компьютер — по ссылке.
Apple Watch получает состояние через связанный iPhone. Данные GrantTap защищены
сквозным шифрованием.

Два способа использовать GrantTap на Mac

Активная Personal включает Mac как managed-клиент без дополнительной покупки
Mac Local. Mac только в роли контроллера не занимает место исполнителя и не
требует локального MCP. MCP нужен на каждом компьютере, где работают агенты.

Mac Local — отдельная разовая покупка $39,99 в США для локального управления
и личного/внутреннего использования своего relay. Personal для этого режима
не нужна; managed-хостинг не включён. Прямой режим использует зашифрованный
поиск endpoint, собственный relay — ваш endpoint. Вы обеспечиваете доступный
TLS или VPN и свою инфраструктуру. APNs-ключи и гарантированная фоновая доставка
не включены. Восстановление — с Apple Account покупателя.

Планируемые месячные цены в США: Personal $3,99 — до 2 компьютеров,
Personal Plus $6,99 — до 5, Fleet $11,99 — до 15. Основные возможности одинаковы;
отличается лимит managed-компьютеров-исполнителей. Агентов и задачи отдельно
не тарифицируют. Модели и токены оплачиваются отдельно. Локальную цену и
подходящий семидневный trial показывает окно Apple. Подписка продлевается
автоматически до отмены в настройках Apple. Apple показывает даты смены плана.
Отмена не удаляет полученные локальные данные и не отменяет купленную Mac Local.
Fleet — личный лимит компьютеров, а не корпоративный SLA.
