## English (U.S.)

### Subtitle

`Control your coding agents`

### Promotional text

See local agent work, review changes, answer questions and manage Project Mesh from Mac. Optional Personal service connects your devices with encrypted delivery.

### Description

GrantTap is a personal control center for coding agents running on your Mac.
Install the separate GrantTap MCP, then see live tasks, inspect conversations,
review recorded file changes, approve actions and send messages or queue them
for later. Local access is authorized on this Mac; GrantTap does not provide
an AI model or proxy model traffic.

Project Mesh keeps a Task stable across provider sessions and computers.
Inspect confirmed usage, tools, skills and repository evidence where reported.
Unavailable measurements stay unavailable. Hidden reasoning is not forwarded.
Claude Code and Codex are primary integrations; Cursor is Beta. Other providers
work only where their supported controls are available.

Connect iPhone or iPad from Settings with a one-time QR, or add a computer by
link. Apple Watch receives state through its paired iPhone. GrantTap payloads
are end-to-end encrypted. Built-in Help, Terms, Privacy and licenses are
available from Settings and the Mac menus, including offline.

Mac License: a one-time $39.99 US non-consumable purchase unlocks Mac local
control and personal/internal own-relay setup. Restore it with the same Apple
Account. A Personal subscription is optional and does not replace this license.
Direct mode uses a short-lived encrypted address directory; fully self-hosted
mode uses your endpoint for pairing and delivery. Supply a reachable TLS proxy
or VPN. Router ports, APNs credentials and guaranteed background delivery are
not included. Computers in one room use the same relay endpoint.

Subscription: Personal managed delivery is $1.99/month for one computer,
$3.99/month for up to five or $5.99/month for up to ten, with a seven-day trial
for eligible new subscribers. Agents are not counted. Local prices and trial
eligibility follow Apple's purchase sheet. Subscription renews automatically
unless cancelled at least 24 hours before the period ends; manage it in Apple
settings. Cancelling Personal does not revoke the Mac License. Apple handles
billing and refunds. Model-provider charges are separate.

### Description

GrantTap — личный центр управления coding-агентами на вашем Mac. Установите
отдельный GrantTap MCP, наблюдайте задачи, читайте чаты, проверяйте записанные
изменения файлов, подтверждайте действия и отправляйте сообщения сразу или в
очередь. Локальный доступ подтверждается на этом Mac. GrantTap не предоставляет
модель ИИ и не проксирует трафик модели.

Project Mesh сохраняет Task при смене сессии, провайдера и компьютера. Смотрите
подтверждённую статистику, инструменты, skills и данные репозитория. Если замер
недоступен, приложение не придумывает цифру. Скрытые рассуждения не передаются.
Основные интеграции — Claude Code и Codex; Cursor — Beta. Другие провайдеры
поддерживаются только в пределах доступных реализованных действий.

Подключайте iPhone или iPad из Settings одноразовым QR, компьютер — по ссылке.
Apple Watch получает состояние через связанный iPhone. Данные GrantTap защищены
сквозным шифрованием.

Mac License — разовая покупка за $39,99 в США для локального управления и личного/внутреннего
использования своего relay. Восстановление покупки использует тот же Apple
Account. Подписка Personal необязательна и не заменяет лицензию. Прямой режим
использует краткоживущий зашифрованный каталог адресов, автономный — ваш endpoint
для пейринга и доставки. Нужен доступный TLS proxy или VPN. Порты роутера,
ключи APNs и гарантированная фоновая доставка не включены. Компьютеры одной
комнаты используют общий endpoint.

Подписка Personal оплачивает управляемую доставку: $1,99/месяц за один компьютер,
$3,99 — до пяти, $5,99 — до десяти, с семью пробными днями для подходящих новых
подписчиков. Агентов не считают. Локальные цены и право на пробный период
указаны в окне Apple. Подписка продлевается автоматически, если не отменить её
минимум за 24 часа до конца периода. Управляйте в настройках Apple. Отмена
Personal не отменяет Mac License. Оплату и возвраты обрабатывает Apple; расходы
